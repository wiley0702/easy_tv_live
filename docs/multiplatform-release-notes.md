## 本次更新

- Windows 常用频道列表支持“切换分组不换台”：切换分组仅浏览频道，点击具体频道才播放；重新打开列表定位到正在播放的频道。
- 分开处理浏览分组与播放位置，修复跨分组同序号频道的高亮和点击判断；节目单跟随实际播放频道。
- 包含前一版的源管理优化：不再内置默认源，所有源可删除，每个源独立更新并显示最近成功更新时间。
- 添加和编辑网络源时可直接填写标题及 User-Agent，兼容 URL 参数；User-Agent 仅用于视频播放请求。
- 隐藏赞赏入口，保留订阅扫码推送；更新中英文说明。
- 此次不修改“进入设置时暂停播放”的行为。Android TV 专用遥控器频道列表仍沿用原交互，尚未验证该界面。

公开版本号保持 **2.9.9**，应用内追加打包日期，内部构建号递增。

## 下载说明

- `-windows.zip`：Windows x64，完整解压后运行 EXE，保留 DLL 和 data 目录。
- `.apk` / `-tv.apk`：Android 手机 / Android TV，ARM64，复用本 fork 的独立签名。
- `-macos.zip`：macOS 构建。
- Linux 提供 tar.gz、deb、rpm 和 AppImage。
- `.ipa` 为未签名 iOS 包，需自行签名；`-apple-tv.ipa` 是 iOS 大屏布局构建，**不是原生 tvOS 安装包**。
- `SHA256SUMS` 提供全部平台包及更新清单的校验值。

Android 独立签名证书 SHA-256：`B6:37:63:86:78:BB:09:1D:BF:85:10:05:BA:92:13:5C:3B:E2:10:E4:FC:45:91:98:81:6E:18:C0:13:C1:E5:84`。此签名不能直接覆盖原作者签名的安装包。
