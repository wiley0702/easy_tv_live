本项目由 Codex 辅助维护，主要供个人自用。**只有 Windows 11 做过运行验证；Android、Android TV、iOS、macOS、Linux 未实机验证。** 构建成功不代表实机验证通过。

## 本次更新

- Windows 增加窗口置顶按钮及 `Ctrl + Shift + T` 快捷键，置顶后图钉高亮，重启不保留状态；仅软件获得焦点时响应。

- README 的变更列表改为本 fork 相比原版的累计功能差异。

新增置顶功能的 3 项自动化测试通过，本地 Windows Release 编译通过；此前便携存储已由用户验证。置顶功能的桌面交互验证被用户中止，完整实机验证尚未完成。局域网双设备配对也尚未实机验证。

## 下载说明

- `-windows.zip`：Windows x64 普通版，数据存于 AppData。
- `-windows-portable.zip`：Windows x64 便携版，数据存于软件目录的 `user_data`。完整解压到可写目录，保留 `portable.flag`。升级保留 `user_data`，迁移时退出软件后复制整个目录；本地文件源的原文件与路径另行迁移。发布包不含个人数据。
- `.apk` / `-tv.apk`：Android 手机 / Android TV ARM64，使用本 fork 既有独立签名。
- `-macos.zip`：macOS 构建。
- Linux 提供 tar.gz、deb、rpm 和 AppImage。
- `.ipa` 为未签名 iOS 包，需自行签名；`-apple-tv.ipa` 是 iOS 大屏布局构建，不是原生 tvOS 包。
- `versions.json` 为更新清单，`SHA256SUMS` 提供附件校验值。

公开版本号仍为 **2.9.9**，应用内显示打包日期，内部构建号递增。

## 临时配对码

订阅推送、同步和电视远程配置需输入接收设备上显示的六位配对码。码五分钟有效，连续输错五次需等待三十秒。会话三十分钟有效，关闭接收页面立即失效；更换配对码不撤销已建立的会话。双向同步要求两端均使用新版客户端。
