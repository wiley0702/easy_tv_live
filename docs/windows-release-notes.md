本项目通过 Codex 辅助维护，主要供个人自用。本次仅发布 Windows x64 包，运行验证范围为 Windows 11，其他系统和设备尚未验证。

公开版本号保持 2.9.9，应用内显示本次打包日期，内部构建号独立递增。

- 移除内置默认源及自动添加逻辑；保留用户订阅，清理旧内置源记录。
- 所有源均可删除，包括当前源；删除最后一个源后保持空列表。本地文件本身不会被删除。
- 每个源独立更新并显示最近成功更新时间；更新失败保留缓存及时间，更新未使用的源不切换播放。
- 添加和编辑网络源时可直接填写显示标题和 User-Agent，兼容 URL 的 tl、ua 参数。User-Agent 仅用于视频播放请求。
- 隐藏扫码赞赏及赞赏榜入口，保留订阅源扫码推送。
- 更新中英文 README、Windows 使用与构建说明，保留上游致谢。

下载 Windows ZIP 后完整解压，运行 easy_tv_live.exe；请保留同目录 DLL 和 data 文件夹。SHA256SUMS 提供附件校验值。

此 Windows 专用 Release 不替换上一版跨平台 Release 的 Latest 标记，避免其他平台收到缺少对应安装包的更新提示。请从本 Release 页面手动下载。
